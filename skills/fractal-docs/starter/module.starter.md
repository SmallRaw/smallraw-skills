# 命令检查模块

负责识别工具输入中的执行命令，再交给策略判断。

## 范围与流程

覆盖输入解析与命令提取；策略规则由独立模块负责。
输入 → 区分执行代码与补丁数据 → 提取命令 → 策略判断。

## 修改前需要知道

补丁正文不能直接当执行代码扫描，其中的普通文本会造成误报。可以更换解析实现，但必须保留这项区分；若输入协议不再混合代码与数据，可以重新评估。
